the proof ladder

Every run names the rung it reached.

A report that doesn't name a level isn't a proof.

L0static-validManifest parses and passes schema validation.
L1builds/loadsService builds or loads without errors.
L2unit-greenUnit tests pass.
L3up+healthyService starts and health probe returns 200.
L4effect-verifiedA drive verb produced an observable effect.
L5end-to-end observedFull user-facing flow exercised and confirmed.

how it works

One manifest. Any substrate. A bundle that doesn't lie.

ready.yaml

Readiness manifest

How a service becomes runnable and testable — deps, seed, health probe, drive verbs — declared once.

service: basic-orders
run:
  ready:
    http: ":8391/healthz"
checks:
  - name: order-roundtrip
    level: L4
    exercise: drive.create-order
    expect:
      - "exitCode(order-roundtrip)==0"
      - "rows(orders.json)>0"
