    the honesty panel

    What this seal proves — and what it cannot.

    What it proves

    • The merge WORKS: a real store delta (execution_entity.max_id 0→1), confirmed by a fresh out-of-band re-read, reproduced across k=2 fresh worlds.
    • The change is why: the identical walk on the parent could not determine — the feature is absent there.
    • The verdict was set last, by fixed rules over receipts — the agent could not write it.
    • Tamper-evidence: every receipt is content-addressed and the whole bundle is signed. Edit one byte → the digest no longer matches.

    What it cannot prove

    • Tamper-resistance: on the box owner's own machine the key and run live on hardware they control — they can forge at rest. This is the honest local tier.
    • The in-browser check verifies content addresses and the manifest digest; the ed25519 signature over that digest is verified by verifySeal in Node.
    • Whether the parent predates a different regression — CND means feature-absent, not "known-good before."
    • Anything outside the walked surface — the case file scopes itself to exactly what was exercised.
