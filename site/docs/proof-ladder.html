Proof ladder

The proof ladder is the L0–L5 scale of verification depth every run must name, from L0 static-valid to L5 end-to-end observed; the rung reached is the run's proof level.

Every pb verify run names the rung reached. A report that doesn't name a rung is not a proof. The rung reached is named in every report — never "done".
L0static-validManifest parses and passes schema validation — "schema-valid ≠ runs."
L1builds/loadsService builds or loads without errors.
L2unit-greenUnit tests pass.
L3up+healthyService starts and health probe returns 200 (or the declared tcp/exec probe succeeds).
L4effect-verifiedA drive verb produced an observable effect — data row, API response, file write. "Wired ≠ runs" gets settled here.
L5end-to-end observedFull user-facing flow exercised and confirmed.

Why a ladder, not a checkbox

Proofbench encodes the builder-copilot lessons directly into the schema: schema-valid ≠ runs; wired ≠ runs. A rung is only reached when its evidence exists in the bundle — a check that records not-run does not silently count toward a higher level. Verify the effect, not the exit status; validate against the declared contract, not the tool's own report.

How the rung is set

Each check in ready.yaml declares the level it proves. When pb verify runs, every declared check appears in the evidence bundle's checks[] with a tri-state result:

pass fail not-run

The bundle's proofLevel is the highest rung whose checks all passed — a single not-run or fail at a level caps the reported rung below it. A run that only proves L3 reports L3, even if an L5 check exists in the manifest but couldn't execute. See the evidence bundle reference for the exact schema, and a real bundle where three checks are honestly not-run while the reported proof level stays at L3.

Example report

pb verify --manifest ready.yaml --ticket ENG-001 --claim "orders endpoint appends to orders.json"
bundle: evidence/20260704-101500-verify
proof: L4
verdict: pass
  [pass] up
  [pass] order-roundtrip

Two L3/L4 checks both passed, so the report names proof: L4 — the highest rung actually reached, stated plainly next to the verdict.
