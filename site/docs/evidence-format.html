Evidence bundle format

Normative field-by-field reference for evidence/<runId>/manifest.json, generated from spec/v0/evidence-v2.schema.json. Descriptions below are the schema's own — for the concepts behind these fields (tri-state, provenance, pairing, seal), see evidence & provenance.

manifest.json — top level

Required: schema, runId, claim, phase, startedAt, artifacts, verdict.

FieldTypeRequiredDescription
schemainteger (const 2)yesBundle schema version. Must be 2 for evidence bundle v2.
ticketstringnoOptional ticket or issue identifier this bundle is attached to (e.g. 'ENG-20190').
runIdstringyesUnique, human-readable run identifier. Conventionally '<YYYYMMDD>-<HHMMSS>-<phase>' (e.g. '20260704-101500-reverify').
claimstringyesOne-sentence statement of what this run is intended to prove (e.g. 'sync(verse) propagates to sequenceNote on release').
phasestring (enum)yesLifecycle stage this bundle documents. One of: repro (reproduce the problem), verify (first verification), reverify (re-check after a fix), fix (the fix run itself), report (summary/rollup).
kindstring (enum: before, after)noPairing role within a before/after pair: 'before' or 'after'. Omit when the bundle stands alone.
pairsWithstringnorunId of the complementary bundle in a before/after pair. Bundles pair by explicit ID, not by convention.
surfaceobject (map<string,string>)noFree-form key-value map describing the execution surface (e.g. substrate, cluster, env). Kept as a flat map so it is substrate-agnostic.
pinsobject (map<string,string>)noKey-value map of exact versions/SHAs for every artifact exercised, making the run reproducible (e.g. repo commit, image digest).
proofLevelstring (enum L0–L5)noHighest proof-ladder rung reached by this bundle. L0=static-valid, L1=builds/loads, L2=unit-green, L3=up+healthy, L4=effect-verified, L5=end-to-end observed.
startedAtstring (date-time)yesRFC 3339 timestamp when the run started.
finishedAtstring (date-time)noRFC 3339 timestamp when the run finished (including verdict seal). Omitted if the run was abandoned.
checksCheck[]noOrdered list of machine-evaluated predicate results. Every declared check must appear, using 'not-run' rather than omitting — never default-green.
artifactsArtifact[]yesOrdered list of all captured files and links in this bundle directory. Set at verdict-seal time; unregistered files are auto-registered.
verdictstring (enum)yesOverall outcome of the bundle, set last from artifacts and checks. Tri-state: pass (all checks passed), fail (at least one check failed), inconclusive (checks could not run, e.g. a human gate blocked execution).
notestringnoHuman-readable annotation on the verdict (e.g. reason for inconclusive, override rationale).

checks[] (Check)

A machine-evaluated predicate result. State is explicitly tri-state — not-run must be used rather than omitting a check that did not execute. Required: name, state.

FieldTypeRequiredDescription
namestringyesUnique name of this check within the bundle, matching the corresponding CheckSpec in ready.yaml where applicable.
statestring (enum)yesTri-state result: pass (predicate held), fail (predicate did not hold), not-run (check was declared but could not execute).
levelstring (enum L0–L5)noProof-ladder rung this check contributes to (e.g. 'L4'). Mirrors CheckSpec.level from ready.yaml.
expectstringnoThe predicate expression declared for this check (e.g. 'db.orders.rows > @before').
observedstringnoThe actual observed value that was evaluated against the predicate (e.g. '42 > 17').
reasonstringnoExplanation for a fail or not-run result (e.g. 'gate: cluster deploy pending', 'exit code 1').
artifactsstring[]noNames of artifacts (matching Artifact.name) that provide evidence for this check's result.

artifacts[] (Artifact)

One captured file or link inside the bundle directory. Provenance distinguishes harness-collected from agent-supplied artifacts (anti-fabrication). Required: type, name, path.

FieldTypeRequiredDescription
typestring (enum)yesArtifact kind: command (captured shell command with exit code), snapshot (before/after data snapshot), screenshot (UI screenshot), log (free-form log file), recording (video/trace recording), link (external URL reference).
namestringyesShort identifier for this artifact, used as a reference key in Check.artifacts. Must be unique within the bundle.
pathstringyesRelative path to the artifact file within the bundle directory (e.g. '03-fire.log'). For type 'link', this is the URL.
sha256string (64 hex)noHex-encoded SHA-256 digest of the artifact file. Omitted for type 'link'. Used for tamper-evidence.
provenancestring (enum)noWho produced this artifact (ADR-0013): 'harness' (teed subprocess captured by the pb harness), 'tool' (harness-directed external tool output — trace/screenshot the harness chose but did not tee), or 'agent' (supplied by the agent — requires scrutiny).
metaobjectnoType-specific metadata. For 'command': cmd (string), exitCode (integer), durationSec (number). For 'snapshot': table (string), rowsBefore (integer), rowsAfter (integer). Other types may use free-form keys.

The Go types in internal/evidence/types.go are the source of truth — any discrepancy between those types and this schema is a bug in the schema, not the types (see versioning policy).
